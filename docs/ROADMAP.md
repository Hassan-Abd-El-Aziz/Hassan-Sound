# MySound — Roadmap & Execution Checklist

وثيقة تتبع تقدم المشروع بالمراحل التفصيلية والمهام المنجزة ومعايير القبول (Acceptance Criteria).

---

## 🧭 الفلسفة العامة للتنفيذ
- تنفيذ مرحلة واحدة في كل مرة بدقة عالية واكتمال منطقي.
- عدم الانتقال من مرحلة إلى أخرى دون اجتياز البناء والاختبارات وموافقة المستخدم.
- الأمان أولاً: لا أسرار، Buckets خاصة، صلاحيات RLS صارمة.
- تجربة مستخدم حقيقية: عدم الاكتفاء بالرسومات الصامتة، وربط العناصر بمنطق حقيقي.

---

### Phase 6 — التخزين والتشغيل بدون اتصال (Offline Architecture) `[مكتملة]`
- [x] إعداد قاعدة بيانات IndexedDB عبر مكتبة Dexie.js لتخزين المسارات والأغلفة كـ Blobs.
- [x] عزل سجلات التنزيل لكل جهاز بشكل مستقل وعدم فرض التنزيل على الأجهزة الأخرى.
- [x] التحقق الصارم من اكتمال التنزيل وحجم الملف وبصمة التشفير قبل وسم الملف كـ `downloaded`.
- [x] تشغيل الملفات المنزلة محليًا من IndexedDB دون الحاجة للاتصال بالإنترنت.
- [x] منع محاولة الاتصال بالسحابة للأغاني غير المنزلة عند انقطاع الإنترنت وإظهار تنبيه دقيق للمستخدم.
- [x] زر حذف التنزيل المحلي يحرر مساحة هذا الجهاز فقط ولا يمس الملف السحابي.
- [x] زر تفريغ التنزيلات بالكامل يخص هذا الجهاز ويطلب تأكيدًا.
- [x] إدارة مساحة التخزين عبر `navigator.storage.estimate` وطلب تثبيت التخزين الدائم `navigator.storage.persist`.
- [x] شرح وتوثيق قيود المتصفح وسياسات إخلاء الذاكرة المؤقتة.
- [x] اختبارات وحدة متكاملة لـ IndexedDB ومخزن التنزيلات.
